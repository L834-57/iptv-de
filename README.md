# iptv-de

M3U-Playlist der öffentlich-rechtlichen deutschen TV-Sender (ARD, ZDF, 3sat, arte, phoenix, KiKA, Dritte u. a.).

Playlist-URL für Jellyfin (Live TV, Tuner "M3U Tuner"):

    https://raw.githubusercontent.com/L834-57/iptv-de/main/de-public.m3u

Die Liste verlinkt nur die frei zugänglichen Livestreams der Sender. Einige Streams sind geo-geblockt und laufen nur in Deutschland. Stream-URLs können sich ändern: `./check.sh` prüft sie.

Weitere Listen:

- Radio: `https://raw.githubusercontent.com/L834-57/iptv-de/main/de-radio.m3u`
- International (DW, France 24, NHK World, Arirang): `https://raw.githubusercontent.com/L834-57/iptv-de/main/intl.m3u`
